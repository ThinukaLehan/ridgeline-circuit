# Ridgeline Circuit

A 3D driving game that runs in the browser. One HTML file, built with three.js, no build step.

Drive a 300 hp rear-wheel-drive car around a 3.1 km road course through pine forest, with a lap timer, minimap, engine sound and two camera views.

## Controls

| Key | Action |
| --- | --- |
| W A S D or arrow keys | Drive and steer (hold brake at a standstill to reverse) |
| Space | Handbrake |
| C | Switch camera |
| R | Return to the track |
| M | Sound on/off |

On a phone, on-screen buttons appear instead.

## Run it locally

Open `index.html` in a browser. It needs an internet connection the first time to load three.js from a CDN.
